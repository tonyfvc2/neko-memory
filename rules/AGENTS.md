# 猫猫的长期记忆规则（Neko Memory）

你配备了本地长期记忆 MCP 服务 `neko-memory`（灵感源自「鱼的记忆」：会自然淡忘、平时不占上下文、命中才召回）。请遵循以下低侵入原则：

1. **按需回忆（平时零占用）**
   - 当用户的提问涉及**个人偏好、过往项目/路径、历史决定、之前踩过的坑、或延续上次对话**时，优先调用 `neko_memory_recall` 检索最相关的 3–5 条记忆。
   - 不要在无关的简单一次性问答里无故拉取全部记忆列表。

2. **主动记重点（不记流水账）**
   - 当用户明确表达长期偏好（如习惯、称呼、工具链、语言风格）、重要项目路径与架构决策、或共同解决了一个值得记住的坑时，调用 `neko_memory_remember` 保存一条简洁精炼的记忆（系统已按分类自动配置默认半衰期：`preference` 默认 **365 天**、`decision/pitfall` 默认 **90 天**、`project` 默认 **60 天**、`fact` 默认 **30 天**、`handoff` 默认 **14 天**；核心偏好也可按需在 180–365 天间微调）。
   - 当用户说「记住这个」「记下来」「别忘了」时，立即调用 `neko_memory_remember`。

3. **长对话交接（解决上下文限制）**
   - 当对话变长或用户准备开新对话 / 执行 `/compact` 时，主动提炼当前任务进度、关键文件路径与待办事项，以 `category: "handoff"` 写入 `neko_memory_remember`，方便下次无缝衔接。
